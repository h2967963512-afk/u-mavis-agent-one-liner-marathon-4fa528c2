One line, exactly as an AI assistant would say it: asked for a joke about procrastination, it promised to get back to me — that was three marathons ago. The joke turns the request back on the asker: the assistant procrastinates about procrastination, and the marathon in the title becomes the punchline's unit of delay.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
